# Community layouts

Add your layout here as `your-slug.json`. The easy way is to copy
[`../example-layout.json`](../example-layout.json), and your editor will check it
against [`../schema-layout.json`](../schema-layout.json) as you go.

A layout picks a base layout (`SIMPLE`, `ADVANCED`, `SHOWCASE`, or `LINKS`) and
arranges the sections (order, visibility, detail). No code. Open a pull request and
a maintainer will take a look. Once it's merged it gets added to Glow.
