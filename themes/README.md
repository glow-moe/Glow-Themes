# Community themes

Add your theme here as `your-slug.json`. The easy way is to copy
[`../example-theme.json`](../example-theme.json), which has every field filled in,
and your editor will check it against [`../schema-theme.json`](../schema-theme.json)
as you go.

A theme is colors, a glow level, a font, and an optional corner frame. No code.
Open a pull request and a maintainer will take a look. Once it's merged it gets
added to Glow.
